# Recipes REST API

A RESTful API for recipe management built with Node.js, Express, and MongoDB.

---

## Features

- Create recipes
- Read recipes
- Update recipes
- Delete recipes
- REST API
- MongoDB persistence

---

## Tech Stack

- Node.js
- Express
- MongoDB

---

## API Endpoints

GET /recipes

GET /recipes/:id

POST /recipes

PUT /recipes/:id

DELETE /recipes/:id

---

## Installation

```bash
npm install

npm start
```
